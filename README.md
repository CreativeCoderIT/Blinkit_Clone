# Blinkit Clone
A modern and responsive Blinkit Clone website built using HTML, CSS, and JavaScript.

## 🚀 Features
- Responsive Design
- Modern UI
- Product Categories
- Search Bar
- Add to Cart UI
- Navigation Bar
- Mobile Friendly Layout

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 📂 Project Structure
```bash
Blinkit_Clone/
│── index.html
│── style.css
│── script.js
│── images/
```
